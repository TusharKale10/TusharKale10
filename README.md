## <img src="https://media.giphy.com/media/hvRJCLFzcasrR4ia7z/giphy.gif" width="26" /> &nbsp;About

I'm a third-year Computer Engineering student in **Pune** who spends most of his free time shipping things that solve problems I actually have.

That instinct is the throughline. Task apps tell you *what's* due but never *what's at risk* — so I built an AI planner that predicts deadline slippage before it happens. Every AI tool I use forgets everything the moment I switch tabs — so I built a local-first context layer with an MCP server that carries my working context between them. Screen-time dashboards count hours but never say when usage tips into harm — so I built a system that scores digital-health risk against real physical signals.

I write across the stack: **React + Node/Express + MongoDB** for products, **Python/FastAPI** when the workload turns computational, and **Java + JSP + MySQL** from my internship. I care about the parts people skip — auth done properly, APIs that don't fall over, and a README good enough that a stranger can run the thing.

### 🧠 ECHO — *Every Context Held, Owned*

**A user-owned context layer for AI tools.**

Every AI assistant starts from zero, so you re-explain your work over and over. ECHO captures ambient signals — active project, git branch, current file, docs you read — stores them locally, and carries that context between Claude, ChatGPT, and Cursor.

`Python` `FastAPI` `React 18` `TypeScript` `Tailwind` `MCP` `on-device embeddings`

- 🛰️ Ambient detection of app, repo, branch & file
- 🔌 **MCP server** exposing context to Claude Code + Cursor
- 🎫 **Context Passport** — portable snapshot for any AI
- 🔒 Fully local processing, secrets redacted, zero keylogging
- 🕸️ Memory graph linking work by shared files & repos
